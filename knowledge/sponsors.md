## Supabase (contact: Isabelle Roser, community programmes)
Hosted Postgres with auth (incl. magic links), realtime, storage, edge functions, auto APIs, pgvector. Free plan is enough. Quickest start: create a project, have Cursor scaffold Next.js + Supabase auth. Fit: shared DB of members/events/RSVPs, live "who's here / who should meet" board.

## Cognee (contact: Veljko Kovac, Head of Forward Deployed Engineering)
Open-source AI memory: turns docs and chats into a searchable knowledge graph. add -> cognify -> search loop; REST API (`/api/v1/add`, `/cognify`, `/search`), MCP server, Python and Node SDKs. Free locally (`pip install cognee` or Docker); cloud free workspace with 10M tokens. Fit: a "community brain" of who said what, who knows whom, skill overlap; best match for "use of community context". Contact publicly invited people to build with Grok and Cognee.
Docs: https://docs.cognee.ai
